# Инструкция по деплою на Vercel

## Способ 1: Деплой через Vercel CLI (быстрый способ)

1. Убедитесь, что вы авторизованы в Vercel:
```bash
vercel login
```

2. Деплой проекта:
```bash
vercel
```

3. Для продакшн деплоя:
```bash التنميةvercel --prod
```

## Способ 2: Деплой через GitHub (рекомендуется)

1. Создайте репозиторий на GitHub:
```bash
# Если репозиторий еще не создан на GitHub
git remote add origin https://github.com/ВАШ_ЮЗЕРНЕЙМ/Название_репозитория.git
git branch -M main
git push -u origin main
```

2. Зайдите на https://vercel.com
3. Нажмите "Add New Project"
4. Подключите ваш GitHub репозиторий
5. Vercel автоматически определит настройки и задеплоит проект

## Настройки Vercel

Проект уже настроен с template `vercel.json`:
- Главная страница: `homescreen.html`
- Кеширование настроено для оптимизации

## После деплоя

Ваш сайт будет доступен по адресу типа:
`https://ваш-проект.vercel.app`

---

**Важно:** Убедитесь, что все пути к файлам (CSS, JS, изображения) работают правильно после деплоя.
